# 更新记录

## 0.10.6 - 2026-11-13

- 机器已经有可用测试地址时，不再在“角色 / 地址”列显示地址探测感叹号。
- 地址探测提示不再把只有私网网卡的机器直接判定为 NAT；改为说明云厂商弹性公网/地址映射，并明确仅 IPv6 测试不可用。

## 0.10.5 - 2026-11-13

- 新增 `PANEL_TRUSTED_PROXY_CIDRS`，允许把远端 HTTPS 反代 IP/CIDR 加入可信代理列表。
- 可信代理来源会采信 Cloudflare/1Panel 传入的真实客户端地址，修复所有 Agent 都被记录成反代机公网 IP、测试连接错误目标的问题。
- 管理端口仍只接受命中固定 CIDR 或代理密钥的转发头，公网直连客户端不能自行伪造来源地址。

## 0.10.4 - 2026-11-13

- 移除安装器的外部反代探测、公网 URL 分支、HTTP 明文警告、NAT 映射提示和内网 IP 输出。安装器只负责启动面板并打印公网 HTTP 地址。
- Agent 接入命令改为始终使用浏览器当前 `origin`：HTTP 访问生成 HTTP 命令，HTTPS 域名反代访问生成 HTTPS 域名命令。
- 服务端同时识别 `X-Forwarded-Proto`、`X-Forwarded-Host` 和 `X-Forwarded-Prefix`，兼容任意 HTTPS 反向代理。
- Agent 独立监听默认收回 `127.0.0.1`，不再额外公开随机端口；反向代理只需转发管理端口。
- README 精简为安装、HTTPS 反代、升级三部分。
- README 恢复顶部 LinkPilot 品牌图；项目页面图标与 favicon 原本未删除。

## 0.10.3 - 2026-11-13

- 安装命令直接接受 `PANEL_PORT`、`PANEL_BIND`、`PANEL_PUBLIC_URL` 覆盖，不再要求先手写 `.env`。
- 传入 `PANEL_PUBLIC_URL=https://...` 即进入 HTTPS 反代模式：自动关闭明文 Agent、启用 Secure Cookie，并打印可直接填进 Nginx/Caddy 的上游地址。
- 反代模式不再输出直连 NAT 映射和 HTTP 明文警告；这些提示只属于没有公网 HTTPS 地址的直连模式。
- README 精简为安装、HTTPS 反代、升级三部分。
- 该安装期反代分支过于隐式，已在 0.10.4 删除；现在反代完全透明，不需要任何公网 URL 参数。

## 0.10.2 - 2026-11-13

- 恢复“新装后直接可用”的默认体验：管理面从仅监听 `127.0.0.1` 改为默认监听 `0.0.0.0`，不再要求先配 SSH 隧道或 HTTPS 反向代理。
- 安装脚本自动探测公网 IPv4，并在完成横幅中打印直连 URL；检测到 NAT 时会提示所需的公网到内网端口映射。
- 无 TLS 直连模式自动允许 Agent 使用同一个 HTTP 入口，避免面板能打开但无法添加机器。HTTP 为明文传输，公网部署仍需用安全组限制来源。
- 保留 `PANEL_BIND=127.0.0.1` 作为显式覆盖，原有反向代理和升级配置不会被强制改写。

## 0.10.1 — 2026-11-09

- 移除 0.10.0 加入的「异常告警」：面板卡片、`/api/settings` 与 `/api/settings/test-alert`、`app/alerts.py`、测试结束后的告警派发，以及 `settings` / `alert_state` 两张表的建表语句一并删除。

## 0.10.0 — 2026-11-09

- 前端拆分：`index.html` 里的内联 CSS / JS 拆成 `static/app.css`、`static/app.js`，模板只剩 HTML 骨架（185KB → 约 20KB）。静态资源带 `?v=<版本号>`，服务端对带版本号的资源返回 `public, max-age=31536000, immutable`，升级后自动失效。
- 实时刷新改用 SSE：新增 `GET /api/stream`，推送四个数据域（机器 / 测试记录 / 定时任务 / Agent 脚本版本）的指纹，前端只在指纹变化时才去拉对应接口；SSE 连不上时自动退回原来的 8/10/15 秒轮询。长连接上限 4 个、单连接 5 分钟自动断开重连，避免占满 waitress 线程。
- 新增异常告警：`GET/POST /api/settings` 配置 webhook 地址、丢包阈值（默认 1%）、吞吐下限（默认标称带宽的 40%）、冷却时间（默认 600 秒）。每轮测试结束后按阈值挑出异常机器 POST 一次，同一机器在冷却时间内只提醒一次；面板新增「异常告警」卡片，可保存设置并「发送测试」。
- 新增导出：单轮 `CSV` / `JSON`（`/api/runs/<id>/export.csv|json`）、长期对比 `CSV`（`/api/schedules/<id>/export.csv`，按「轮次 × 机器」长表）；CSV 对 `= + - @` 开头的单元格加前缀，避免 Excel 公式注入。
- 测试：新增 `tests/test_settings_export.py`（设置校验、告警阈值与冷却、webhook 实收、CSV/JSON 导出、SSE 首帧与鉴权）。

升级：面板重建镜像生效；本次没有数据库结构变更之外的 Agent 改动（新增 `settings` / `alert_state` 两张表，`CREATE TABLE IF NOT EXISTS` 自动建）。浏览器首次加载会重新下载拆分后的静态资源，之后命中长缓存。

## 0.9.0 — 2026-11-08

- 新增**面板推送 Agent 更新**：机器列表出现「Agent 可更新」徽标，点「更新」或「全部更新 Agent」即可让节点自行升级，不用再重跑接入命令。链路是：面板下发签名任务（含新脚本 sha256）→ Agent 从 `/agent/agent.sh` 下载并核对摘要 → 落到 `/var/lib/linkpilot` → root 一次性助手用 `/etc/linkpilot/update.key`（0600 root，Agent 账号读不到）验签 → 语法检查 → 原子替换 → 重启服务。
- Agent 心跳新增 `X-Agent-Script`（自身脚本 sha256）与 `X-Agent-Caps`（能力），面板据此判断版本是否落后、能否推送。
- 注册响应新增 `update_key`，安装脚本把它写进 root-only 文件；旧 Agent 不带这两个头，面板会提示「需重跑接入命令」。
- 测试改为 `iperf3 -J` 结构化输出：解析不再依赖文本正则，并新增每个方向的稳定性指标（区间吞吐 CV、P95）。
- TCP 测试默认加 `-O`（10 秒及以上的测试剔除前 3 秒、4–7 秒剔除 1 秒），避开慢启动对短测平均值的系统性拉低；UDP 不剔除，保留全部丢包统计。
- 报告里的原始输出块对 JSON 结果做摘要显示（`[SUM] sender/receiver` + 稳定性一行），不再塞整段 JSON。

升级说明：面板重建镜像生效；已接入的节点因缺少 root 更新助手，需要**最后一次**重跑接入命令，之后即可由面板推送。数据库变更为增量补列（`update_key` / `agent_hash` / `agent_caps`），不改动既有数据。

回退代码：回退本版本提交后重建面板。新增列对旧版本无害；已更新过的 Agent 若需回退，重跑旧版本的接入命令即可。

## 0.8.0 — 2026-11-08

- 修复「停止测试」停不掉远端命令：Agent 执行任务期间改为每 3 秒发一次忙碌心跳（`X-Agent-Busy: 1`），面板收到忙碌心跳时只回 `cancel_job=<id>`、不再派新任务；Agent 读到后 kill 掉自己启动的 `iperf3`/`ping`。此前「停止」只置面板标志位，远端命令会跑满时长，既占着目标机端口，又和下一轮抢带宽。
- 修复定时任务历史被手动测试上限连带删除：`prune_history` 按来源分别保留，手动测试默认 100 条、每个定时任务默认 3000 轮，可用 `PANEL_KEEP_RUNS` / `PANEL_KEEP_SCHEDULE_ROUNDS` 覆盖。旧实现用 `DELETE ... WHERE id <= cutoff` 统一清理，5 分钟间隔的任务到第二天对比页就只剩最近约 100 轮，面板却仍显示已完成全部轮次。
- 长期对比的「共 N 轮」改用定时任务累计轮次，不再受历史保留窗口影响。
- 测试记录列表改用一次聚合查询（`db.run_counts_bulk`），去掉每轮一次的 N+1 查询。
- 数据库：新增 `jobs.cancel_requested` 列与 4 个查询索引；连接加 `PRAGMA synchronous=NORMAL` 与 `busy_timeout`，降低高频小写入的落盘开销。
- 容器入口把 SIGTERM 转发给面板进程，`docker stop` 不再等 10 秒后 SIGKILL。

升级说明：面板改动随镜像重建生效；Agent 需重跑一次接入命令才能获得「取消任务」能力（旧 Agent 仍可正常测速，只是停止时不会立刻中止远端命令）。本版本数据库变更为增量补列 + 建索引，不改动既有数据。

回退代码：回退本版本提交后重建面板。新增的 `jobs.cancel_requested` 列与索引对旧版本无害（旧版本不读该列），无需恢复数据库。
