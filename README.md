# LinkPilot

Docker 化的 iperf3 多机线路质量测试面板：一台**目标机**（被测端）+ 多台**后端机**（发起端），逐台测速并生成带线路质量评价的 Markdown 报告。机器通过 Agent 接入，**面板不保存任何 SSH 凭据**。

> LinkPilot 是新的产品名称。为了兼容已有部署和升级，Docker 容器名、`IPERF3_FLEET_*` 环境变量和 Agent 服务名暂时保留 `iperf3-fleet` 标识。

- 一键部署：**同一条命令管安装和升级**（没装过直接装，装过就自动检查更新，有更新才重建）；安装过程安静、带进度与耗时，第三方工具的刷屏输出收进日志文件，最后给一屏结论（地址 / 账号 / 下一步 / 维护命令）
- 测试参数可调：iperf3 线程数 `-P`、单向时长 `-t`、端口 `-p`、TCP / UDP（`-u -b`）、ping 次数 `-c`
- **定时任务**：保存后立即执行首轮，之后按自定义间隔（5 分钟 ~ 30 天）和运行时长（最长 365 天 / 不限）持续测试；支持单线/多线吞吐趋势、上下行筛选、定时记录折叠、带图富文本报告和上下行完整性失败判定
- 测速全局串行（避免互相抢带宽），ping 并行；报告含丢包、RTT、抖动、上下行、重传、线路质量评价与每台原始数据
- 默认 IPv4，双端都有 IPv6 时可切换 IPv6 测试
- 面板容器只读文件系统 + 最小权限运行；端口与登录密码随机生成
- 可选 HTTPS：Caddy 自动签发证书，或 Cloudflare 源证书（配橙云）

## 快速开始

```bash
curl -fsSL https://raw.githubusercontent.com/se-tang/LinkPilot/main/install.sh | bash
```

**同一条命令管安装和升级**：没装过的机器直接装；已经装过的机器重跑一次就会自动检查更新，有新版本才更新并重建（没有就报告「已是最新」），数据 / 端口 / 机器接入关系全部保留，登录密码不变。本地有未提交改动时会先自动存入 `git stash` 备份，再更新到官方最新代码。只想检查更新、先不部署：`... | IPERF3_FLEET_DRY_RUN=1 bash`。

装完会打印面板地址和初始登录账号密码（只显示一次，请立即保存）。脚本会先自检环境，缺 `git` / `docker` 自动装好。

1. 登录面板 → 「添加机器」（名称 / 角色 / 地区 / 带宽）→ 复制**接入命令**，到目标机器上以 root 执行 → 等它上线；
2. 选目标机、勾选后端机，按需设置测试参数 → 「开始测试」（默认 IPv4；要测 IPv6 需双端都支持，会二次确认）；
3. 要长期观察就在「**定时任务**」里挂一个任务（选目标机 / 后端机 / 间隔 / 运行时长），之后点「汇总对比」看全量趋势、跨轮汇总，并复制报告或逐轮数据；
4. 完成后复制或下载 Markdown 报告。删除机器会自动卸载该机器上的 Agent。
