# LinkPilot

多机网络线路测试面板。支持手动测速、定时任务、趋势对比和 Markdown 报告。

## 安装

安装后直接打印公网 HTTP 地址：

```bash
curl -fsSL https://raw.githubusercontent.com/se-tang/LinkPilot/main/install.sh | bash
```

## 升级

重跑安装命令即可，端口、数据、密码和 Agent 关系保持不变。

详细配置见 [部署文档](docs/deploy.md)，参数见 [使用说明](docs/usage.md)。
